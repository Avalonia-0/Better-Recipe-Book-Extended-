# Better Recipe Book (Extended)

This is an unofficial fork of [Better Recipe Book (check out the core features here)](https://modrinth.com/mod/brb), aimed at porting to newer Minecraft versions and extending functionality.

## Extended Features

1. **Scrolling confined to the recipe book** — Prevents page scrolling when the cursor is outside the recipe book area.
2. **Show partially available recipes** (requires enabling in `Configuration → General`). *When enabled, recipes with only some materials available will still appear in the recipe book even when "Show Craftable Only" is turned on.*
3. **Display mod name source** (requires enabling in `Configuration → General`). Mod names can be translated via resource packs using the key `"jade.modName.<namespace>"`.
4. **REI integration** — Items inside the recipe book can be viewed in REI for recipes and usages.
5. **Hide "Craft One to Unlock"** — Suppresses the unlock toast prompt.

## How to Install?

- **Client-side only** — All features work with a client-side installation only. No server-side mod required.
