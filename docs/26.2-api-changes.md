# 26.1.2 → 26.2 API Breaking Changes

## 1. Minecraft.screen → Gui.screen()

**26.1.2**: `Minecraft.screen` (public field, `Screen`)
```java
Minecraft.getInstance().screen
this.minecraft.screen
```

**26.2**: `Minecraft.gui.screen()` (public getter on Gui class)
```java
Minecraft.getInstance().gui.screen()
this.minecraft.gui.screen()
```

Affected files: 16 files across mixins and generic code.

---

## 2. Minecraft.setScreen() → Gui.setScreen()

**26.1.2**: `Minecraft.setScreen(Screen)`
**26.2**: `Minecraft.getInstance().gui.setScreen(Screen)`

---

## 3. Minecraft.getOverlay() → Gui.overlay()

**26.1.2**: `Minecraft.getOverlay()` returns `Overlay`
**26.2**: `Minecraft.getInstance().gui.overlay()` returns `Overlay`

Affected: MouseMixin.java (1 file)

---

## 4. I18n.exists() → ClientLanguage.has()

**26.1.2**: `I18n.exists(String)`
**26.2**: Removed. Use `Minecraft.getInstance().getLanguageManager().getSelected().has(String)`

Affected: ModNameUtil.java (1 file)

---

## 5. Screen API Changes
- `Screen(Component)` constructor → `Screen(Minecraft, Font, Component)`
- No known impact on current mixins (verified by compilation errors)

## 6. AbstractRecipeBookScreen
- Type parameter: `<T extends RecipeBookMenu>` (unchanged, no impact)

## 7. Dependencies
- Fabric API: 0.152.1+26.2 (available)
- NeoForge: NOT YET AVAILABLE for 26.2
- Architectury API: 21.0.1 available but we want to REMOVE it
- Cloth Config: No 26.2 version yet
- ModMenu: Latest is 1.16.3
