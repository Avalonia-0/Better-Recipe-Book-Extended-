# 26.3 鼠标键号改成 SDL3 约定：左=1 / 中=2 / 右=3（BRBE 全量点击判定修正）

## 症状

用户实测：**LEI 查询界面里任何位置左键一点，窗口就直接关掉**（按设计只有右键才关）。

## 根因

26.3 把窗口/输入层从 GLFW 换成了 **SDL3**（`org.lwjgl.glfw` 整包消失，改用 `lwjgl-sdl`），
鼠标键号随之从 GLFW 约定换成 SDL3 约定 —— **左键与右键互换**：

| | 左键 | 中键 | 右键 |
|---|---|---|---|
| 26.2 及更早（GLFW） | 0 | 2 | 1 |
| **26.3（SDL3）** | **1** | **2** | **3** |

证据（`javap` 26.3 客户端 jar）：

- `InputConstants$Type` 静态初始化：`key.mouse.left=1`、`key.mouse.middle=2`、`key.mouse.right=3`；
- 原版 `AbstractContainerScreen.mouseClicked`：`event.button() == 1 || event.button() == 3`
  才走"左键式"槽位逻辑（26.2 是 `0 || 1`）；
- 原版 `RecipeButton.isValidClickButton`：`button()==1 || button()==3`。

BRBE 26.3 的点击判定是**照抄 26.2 的字面量**，于是：

- `RecipeViewerOverlay` 的"右键关窗"写的是 `event.button() == 1` → **左键命中** → 用户看到的现象；
- 所有"左键才处理"的 `event.button() != 0` → 永远成立 → 左键专属分支（放置配方、切标签、
  翻页、拖动窗口、工作站列查询…）**全部失效**。

> 这类字面量编译器不管、mixin 审计也查不到（不是注入点），只有真机点击才能发现。

## 修复

`util/ClientCompat` 新增语义化常量与谓词，**所有硬编码键号一律改用它**：

```java
public static final int MOUSE_LEFT = 1;    // SDL3：左=1、中=2、右=3
public static final int MOUSE_MIDDLE = 2;
public static final int MOUSE_RIGHT = 3;
public static boolean isLeftClick(MouseButtonEvent event)  { return event.button() == MOUSE_LEFT; }
public static boolean isRightClick(MouseButtonEvent event) { return event.button() == MOUSE_RIGHT; }
```

改动点（20 处，覆盖整个点击层）：

| 文件 | 原语义 | 修正 |
|---|---|---|
| `util/RecipeViewerOverlay`（8 处） | 右键关窗 / 左键放置 / 分页按钮 / 标签 / 工作站列 / 拖动 / 页内按钮 | `isRightClick` / `isLeftClick` |
| `util/WorkstationTitleTrigger` | 左键点标题查工作站 | `isLeftClick` |
| `widget/StateSwitchingButton` | 只认左键 | `MOUSE_LEFT` |
| `generic/GenericRecipeButton` | `i == 0 \|\| i == 1`（左右键都算） | `MOUSE_LEFT \|\| MOUSE_RIGHT` |
| `generic/GenericRecipePage` | 左键=放置、右键=展开变体 | `MOUSE_LEFT` / `MOUSE_RIGHT` |
| `generic/GenericRecipeBookComponent` | 右键清空搜索框 | `MOUSE_RIGHT` |
| `smithingtable/SmithingOverlayRecipeComponent`（2 处） | 左键选变体 | `MOUSE_LEFT` |
| `mixins/scrollablepages/RecipeBookPageMixin`（2 处） | 左键滚轮翻页 / Ctrl 跳页 | `isLeftClick` |
| `mixins/pipeline/RecipeBookComponentMixin` | 右键清空搜索 | `isRightClick` |
| `recipebookispain_extended/mixin/widget/RecipeBookWidgetMixin` | 左键点 RBIP 翻页按钮 | `isLeftClick` |

**保持不变**：把 `event.button()` 原样透传给原版控件的调用点（`ClientCompat.mouseClicked`、
`GenericRecipeBookComponent.mouseClicked(x,y,button)` 等）——原版控件在 26.3 已经按 SDL3 判定，
透传是对的；只有**自己写死数字**的地方才需要改。

## 回归范围（这些功能在修复前都是坏的）

LEI 窗口：右键关窗、左键放置配方/预览放置、页内翻页按钮、类别标签、工作站列查询、标题栏拖动。
配方书：左键放置、右键展开替代配方组、右键清空搜索框、滚轮翻页/Ctrl 跳页、RBIP 翻页按钮、
锻造台变体选择、工作站标题查询、设置/过滤按钮。
